南京地铁 UI 修改提交包
版本：原图对齐 · 统一圆形站点
日期：2026-09-28

一、这次改了什么

1. 按小组提供的南京地铁运营线路图重画线路形态
以 3a9e07f92d14a21eac541e49414acd80.jpg 为依据，整理250个站点的显示位置及30处站间转折。恢复10号线向西过江、S2和S9向南延伸、S6和S7向东后折向南、S8先向北再向东，以及7号线北端向东的布局。保持原图横纵比例。

2. 站点标记全部统一
普通站和换乘站都使用相同大小的白底圆点，取消椭圆、胶囊形换乘标记。选中、悬停、起点和终点只改变边框颜色，圆点形状与大小一致。

3. 调整站名排版
站名避让线路、站点和其他文字；避让范围同步改成圆点尺寸。保留项目要求的6.8pt字号。全网缩小时空间不足的站名会隐藏，放大后可显示更多。

4. 改善界面布局和地图操作
压缩顶部标题区域，扩大地图显示区；底部加入可点击的线路导航，选中某条线路时淡化其他线路。右下角提供放大、缩小、还原按钮。还原恢复居中和默认缩放，保留当前乘车方案。

5. 调整查询后的显示
按照实际乘坐线路的颜色突出路线，淡化其他线路和站名。底图绘制、站点点击、搜索定位、路线高亮共用同一套显示坐标，保证地图与操作位置一致。

6. 修正构建配置
修正原协作包构建脚本的源码与输出目录，补齐新增头文件的工程引用，移除指向不存在文件的引用。

二、哪些内容保持不变

保留14条线路、250个业务站点及538条首末车方向记录。
metro_data.txt、service_times.txt、MetroData.cpp、MetroGraph.cpp、RouteStrategy.cpp 与原协作包逐字节一致。
此次调整发生在显示层，不修改原数据坐标、站点顺序、距离、票价计算或寻路算法。
原数据中“草场门”和“草场门·南艺·二师”是两个ID，仍按原数据保留，未擅自合并。

三、主要改动文件（相对于最初的布局协作包）

新增：
OfficialMapLayout.h：原图描摹的站点显示坐标与转折点。
MapLabelLayout.h：站名避让与位置安排。

修改：
MetroLayout.h：统一提供底图、站点命中和路线高亮使用的显示几何。
NanjingMetroView.cpp / .h：线路绘制、统一圆点、站名排版、线路筛选和交互。
MetroViewUI.cpp：顶部布局、线路导航、缩放和还原控件。
MainFrm.cpp：默认隐藏旧式工具栏及重复状态栏。
MapStyle.h：绘制原语与小数描边支持；最终站点圆形样式由视图统一调用。
NanjingMetro.vcxproj / .filters：同步头文件及工程引用。
IntegrationTests.cpp / .vcxproj：显示几何检查和测试工程配置。
01_源码/构建.ps1：修正构建路径并支持指定工具集、Windows SDK。

四、如何运行和交给组长

直接运行：
先将整个压缩包解压，再打开 02_可运行程序/NanjingMetro.exe。
同目录的 metro_data.txt 和 service_times.txt 必须保留。

查看效果：
03_界面对照 中包含用户提供的原图、最新全网截图和圆点放大截图。

源码合并：
01_源码/NanjingMetro 是完整工程，可直接打开 NanjingMetro.vcxproj。
建议先备份组长现有工程，再对照上面的文件列表合并；新增的两个头文件必须一起带上。若组长已继续修改其他代码，请对照合并，不要直接覆盖其未合并改动。

重新构建：
需要 Visual Studio 的 C++ 桌面开发与 MFC 组件。
运行 01_源码/构建.ps1；附加 -Test 可构建并运行集成测试。
本次验证环境为 VS2022 v143、Windows SDK 10.0.26100.0、Release x64。

已实测雨山路到东麒路查询，高亮正确沿10号线过江折线显示。
